Atualize o Android System WebView

O North Code Play utiliza recursos modernos de interface (Tailwind CSS 4) que exigem o Android System WebView 111 ou superior.

  1. Abra a Google Play Store no seu dispositivo Android TV ou celular.
  2. Pesquise por Android System WebView.
  3. Selecione Atualizar e abra o aplicativo novamente.
